# Mac Fase 1 Mídia — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cartão + Tela Mac no painel com Agora tocando e play/pause/prev/next via Agente USB.

**Architecture:** Capability `MEDIA` no Agente (push + comandos). Domínio `mac::` no firmware parseia linhas. Widget `org.tessara.mac` (HomeTile::Mac) pinta cartão só-leitura e tela com três controles. Shell despacha USB sem lógica de produto.

**Tech Stack:** ESP32/LVGL9, Unity native, Python 3 + pyserial, MediaRemote/osascript no Mac.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-10-25-mac-media-design.md`
- Glossário: Mac, Cartão Mac, Tela Mac, Agora tocando, Mac offline
- Só USB; cartão sem botões; sem capa/Focus/Lock/volume
- Push on-change + heartbeat ≤ 10 s; stale painel ~45 s
- Vocabulário UI em PT; ids de protocolo em inglês (`MEDIA`, `PLAYPAUSE`, …)

- [ ] **Step 1: Write failing tests** in `test_mac_snapshot.cpp`:

```cpp
#include <unity.h>
#include "mac/snapshot.h"

void test_mac_apply_playing(void) {
    mac::View v{};
    TEST_ASSERT_TRUE(mac::apply_line(
        v, "MEDIA\tv1\t1\tplaying\tSong\tArtist\tMusic", 1000));
    TEST_ASSERT_TRUE(v.ready);
    TEST_ASSERT_TRUE(v.media.ok);
    TEST_ASSERT_EQUAL(mac::MediaState::Playing, v.media.state);
    TEST_ASSERT_EQUAL_STRING("Song", v.media.title);
    TEST_ASSERT_EQUAL_STRING("Artist", v.media.artist);
    TEST_ASSERT_EQUAL_STRING("Music", v.media.app);
}

void test_mac_apply_paused_keeps_title(void) {
    mac::View v{};
    mac::apply_line(v, "MEDIA\tv1\t1\tpaused\tSong\tArtist\tSpotify", 1);
    TEST_ASSERT_EQUAL(mac::MediaState::Paused, v.media.state);
    TEST_ASSERT_EQUAL_STRING("Song", v.media.title);
}

void test_mac_apply_stopped(void) {
    mac::View v{};
    mac::apply_line(v, "MEDIA\tv1\t1\tstopped\t\t\t", 1);
    TEST_ASSERT_EQUAL(mac::MediaState::Stopped, v.media.state);
    TEST_ASSERT_EQUAL_STRING("", v.media.title);
}

void test_mac_apply_ok0(void) {
    mac::View v{};
    mac::apply_line(v, "MEDIA\tv1\t0\t\t\t\t", 1);
    TEST_ASSERT_TRUE(v.ready);
    TEST_ASSERT_FALSE(v.media.ok);
}

void test_mac_reject_wrong_prefix(void) {
    mac::View v{};
    TEST_ASSERT_FALSE(mac::apply_line(v, "AITOKENS\tv1\t1", 1));
}

void test_mac_stale_after_45s(void) {
    mac::View v{};
    mac::apply_line(v, "MEDIA\tv1\t1\tplaying\tA\tB\tC", 1000);
    TEST_ASSERT_FALSE(mac::refresh_age(v, 1000 + 44999));
    TEST_ASSERT_FALSE(v.stale);
    TEST_ASSERT_TRUE(mac::refresh_age(v, 1000 + 45000));
    TEST_ASSERT_TRUE(v.stale);
}
```
