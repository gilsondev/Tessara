# Agent v2 — companion UI (Tauri) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App Tessera (Tauri 2) com as telas do protótipo `docs/prototypes/agent-ui/`, falando com agentd via IPC localhost — sem USB na UI.

**Architecture:** `apps/agent-ui` = Vite + HTML/CSS do protótipo (ou React leve se o scaffold Tauri preferir; **preferência: portar o HTML estático do protótipo** para reduzir drift). Rust side só: tray, deep link a status, spawn/check agentd. Dados vivos vêm de `http://127.0.0.1:19792`.

**Tech Stack:** Tauri 2, Node 22 (mise), frontend = protótipo adaptado; opcional TypeScript mínimo.

## Global Constraints

- Spec + protótipo: `docs/superpowers/specs/2026-10-25-tessera-agent-v2-design.md`, `docs/prototypes/agent-ui/`
- Português na UI; sem jargão USB na home
- Pré-req: agentd expõe `/v1/status` (daemon plan Task 4); UI pode mockar se agentd down
- Não instalar LaunchAgent Python; opcionalmente detectar legacy e avisar

- [ ] **Step 1: `fetchStatus()`**

```js
const PORT = Number(import.meta.env.VITE_AGENTD_PORT || 19792);
export async function fetchStatus() {
  const r = await fetch(`http://127.0.0.1:${PORT}/v1/status`, { signal: AbortSignal.timeout(800) });
  if (!r.ok) throw new Error("status " + r.status);
  return r.json();
}
```
