# AI Tokens Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cartão + tela de AI Tokens no Tessara, alimentados por Bridge USB no Mac (Codex 24h + Claude statusLine).

**Architecture:** Domínio `aitokens::` parseia linhas `AITOKENS` e expõe `View` (frescor/stale). Console despacha push e o Controller pinta home/tela. Bridge Python em `tools/aitokens_bridge/` lê SQLite/statusLine, empurra a cada 5 s e responde `AITOKENS?`.

**Tech Stack:** ESP32 Arduino + LVGL9, Unity native tests, Python 3 + pyserial + sqlite3, launchd.

## Global Constraints

- Vocabulário: `GLOSSARY.md` (AI Tokens, Bridge, Fonte, desatualizado, indisponível).
- Spec: `docs/superpowers/specs/2026-10-24-ai-tokens-design.md`.
- Não reusar comando serial `TOKEN`.
- Snapshot só RAM; stale ~30 s; push ~5 s.
- Sem settings no celular; sem HTTP de cotas.
