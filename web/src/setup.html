Primeiro uso

Escolha a rede da casa. O token do Todoist pode ficar para depois.

Rede Wi-Fi

Token do Todoist

  1. Abra todoist.com e entre na sua conta.
  2. Toque na sua foto, no canto superior esquerdo.
  3. Abra Configurações.
  4. Abra Integrações e, no topo, Desenvolvedor.
  5. Toque em Copiar token da API e cole abaixo.

Se ficar em branco, a tela inicial mostra de novo este caminho. Emitir um token novo só se o atual falhar: isso sai da conta nos outros aparelhos.

Pronto

Volte para a rede da casa. O painel entra nela sozinho.
