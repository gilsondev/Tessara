# Calendar widget

**Id:** `org.tessara.calendar`  
**Accent:** `#1A73E8`

Read-only Google Calendar agenda for today. Events arrive via the Tessara Agent USB snapshot (`CALENDAR` lines). Account link and calendar selection live on the device web portal; OAuth tokens stay on the Mac.

## Settings (planned)

Namespaced under `org.tessara.calendar` — selected calendar IDs only (no tokens).

## Icons

Material Symbols (`calendar_month`, `event_busy`, `warning`) — Apache 2.0.  
Regenerate: `python3 tools/gen_calendar_icons.py`
